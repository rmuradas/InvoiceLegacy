GESFACT 2.x - programa de facturacion de Suministros Hidalgo
============================================================

INSTALACION (ordenador nuevo de oficina):
 1. Instalar node 8 desde nodejs.org (la version LTS)
 2. Copiar la carpeta gesfact desde \\SERVIDOR\compartido\gesfact
 3. Abrir simbolo del sistema en la carpeta y escribir: npm install
 4. Arrancar con: node server.js
 5. Entrar en http://localhost:3000 (crear acceso directo en el escritorio)
